# Iraq Student Hub

A static, responsive website for Iraqi students. No installation or build step is required.

## Preview

Open `index.html`, or serve this folder with any static web server. Search, filters, saved opportunities, and checklist progress work in the browser. Saved items and progress use local storage; they may not persist in private browsing or when storage is disabled.

## Publish on GitHub Pages

1. Create a public repository on GitHub (for example, `iraq-student-hub`).
2. Upload the **contents** of this folder, including all HTML files and the `assets` folder. `index.html` must be at the repository root.
3. In Settings → Pages, choose **Deploy from a branch**, then **main** and **/ (root)**. Click Save.
4. The site will be at `https://YOUR-USERNAME.github.io/iraq-student-hub/` after deployment completes.

All asset paths and links are relative, so they work with GitHub Pages project URLs. Keep the `.nojekyll` file if uploading with Git.

## Content maintenance

The five detailed guides are preserved from the first, nonduplicated document in the supplied website. Original research dates remain visible. The directory is a research starting point, not a list of currently open applications. Verify cycles, deadlines, eligibility, funding, and visa requirements on the linked official pages before updating the guides.

Edit text in the relevant HTML file, appearance in `assets/styles.css`, and interactions in `assets/app.js`. No account, analytics service, or external font is required.
